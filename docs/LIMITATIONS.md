# Limitations of the suite

This page is the one place every limitation of the suite is listed; a limitation stated
nowhere else in public is marked undocumented here rather than left out. Each row names the
file in this tree that proves it, so a reader can check the row rather than trust it.

Inventory taken 2026-11-25 against the tree at that date. A row is retired when the file
that proves it no longer does; a new limitation gets a row before it gets a workaround.
